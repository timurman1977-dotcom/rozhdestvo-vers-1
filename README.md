# Авторский Рождественский Тур в Европу — Туроператор «Турсалон» (г. Астана)

> **Релиз: Версия 1.0 (v1.0.0)**  
> **Production Vercel**: [https://happytour-three.vercel.app](https://happytour-three.vercel.app)  
> **Резервная копия**: `tursalon-christmas-tour-backup-v1` & `tursalon-christmas-tour-v1.zip`

Премиальный конверсионный одностраничный веб-лендинг, разработанный по методологии **Grand Slam Offer** (Алекс Хормози).

## 📁 Структура проекта
```
tursalon-christmas-tour/
├── index.html            # Главный адаптивный лендинг (HTML5 + Tailwind CSS CDN + Vanilla JS)
├── README.md             # Документация и инструкция
└── images/
    ├── logo.png          # [IMAGE_LOGO] Фирменный логотип «Турсалон» (круглая эмблема с глобусом и самолётиком)
    ├── nina.png / nina.jpg # [IMAGE_NINA] Портрет основателя тура Нины Шахановой в белой рубашке
    └── map.png / map.jpg # [IMAGE_MAP] Иллюстрированная винтажная рождественская карта маршрута
```

## 💎 Дизайн-система и технологии
- **Стек**: Чистый семантический HTML5 + Tailwind CSS (CDN) + Vanilla JavaScript (без внешних зависимостей).
- **Цветовая палитра**:
  - `Primary / Deep Teal`: `#062428`, `#0A3A40` с золотистым атмосферным свечением
  - `Accent / Amber & Gold`: `#FF9E1B`, `#E68A00`, `#D4AF37`
  - `Frosted Glass`: матовые карточки с `backdrop-filter: blur(16px)` и мягкими границами
  - `CTA WhatsApp`: `#25D366` (hover: `#20ba59`) с эффектом мягкой пульсации
  - `Text`: контрастный белоснежный `#FFFFFF` и лунный `#F7F4EE`
- **Шрифты**: Playfair Display / Cormorant Garamond (заголовки) + Montserrat (основной текст).
- **Адаптивность**: 100% Mobile-First, тач-таргеты > 48px, плавающая кнопка быстрой связи WhatsApp.
